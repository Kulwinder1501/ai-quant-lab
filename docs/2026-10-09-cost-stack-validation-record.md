# Record: Cost Stack Validation (H_OFI_REPLENISHMENT)

**Status:** SEALED  
**Date**: 2026-10-09  
**Parent research program:** Phase 28 Microstructure Information Flow  

## 1. Purpose
This is a deterministic accounting study designed to calculate the precise historical execution costs for the 52 valid `Q1` state opportunities generated by the `H_OFI_REPLENISHMENT` exploratory evaluation. 

The original research verdict (which used a theoretical `2.0 bps` friction deduction) remains **unchanged and completely isolated** from this analysis. This document serves as a reality-check promotion gate determining whether the gross edge (+8.42 bps) survives actual Indian futures cost constraints.

## 2. Frozen Parameters & Cost Model
The cost model implements the actual NSE and SEBI statutory rates (effective March/April 2026) applied to precise contract-level lot sizes extracted dynamically from the `instruments` master database.

1. **Brokerage**: The lesser of ₹20 per executed order or 0.03% of turnover.
2. **Statutory & Exchange**:
   - STT: `0.05%` applied strictly to the *sell* turnover.
   - Stamp Duty: `0.002%` applied strictly to the *buy* turnover.
   - NSE Transaction Charge: `₹183` per crore (`0.00183%`) per leg.
   - SEBI Turnover Fee: `₹10` per crore (`0.0001%`) per leg.
3. **Execution Cost (Spread)**: Actual, time-aligned `bid` and `ask` levels were extracted. The spread cost is exactly what was paid historically to cross the touch for the target entry and exit trajectories.
4. **Additional Slippage**: Modeled at a provisional baseline of `0.5 bps` per leg beyond the best bid/ask quote.

## 3. Results (Baseline 0.5 bps Slippage)

Averaging the precise, unrounded per-trade costs across all 52 independent `Q1` opportunities yielded:

| Component | Mean Contribution |
| :--- | :--- |
| **Gross Mid-to-Mid Return** | `+8.42 bps` |
| Quoted Spread Crossing | `-2.45 bps` |
| Additional Slippage (0.5/leg) | `-1.00 bps` |
| Statutory, Exchange, Broker | `-6.23 bps` |
| **Modeled True Net Return** | **`-1.27 bps`** |

*Note: Arithmetic discrepancy between (8.42 - 2.45 - 1.00 - 6.23 = -1.26) and the reported `-1.27 bps` is due strictly to aggregating unrounded individual trade-level records.*

## 4. Final Disposition
- **FALSIFIED AS A RETAIL MARKET-TAKING STRATEGY**. The +8.42 bps gross alpha is robust but deeply insufficient to survive the `-6.23 bps` non-negotiable statutory floor, let alone spread crossing and impact.
- **Sealed Per-Trade Records**: The complete JSON dictionary containing every individual trade's detailed entry/exit time, exact quoted spread, unrounded entry/exit notionals, and componentized INR line-item charges has been preserved at `docs/2026-10-09-cost-validation-report.json`.

All future microstructure research using Phase 28 data is hereby suspended in favor of prospective evaluation on a fresh, synchronized dual-instrument L2 dataset.
